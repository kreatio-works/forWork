# 2級建築施工管理技士 第一次検定 演習ドリル

スマホで使える第一次検定の演習ドリルです。

https://kreatio-works.github.io/forWork/sekou-1ji-drill/

- オリジナル問題45問（解説つき）＋過去問500問（令和3年度前期〜令和8年度前期の10回分、令和6年度前期を除く。全問に独自作成の解説つき）
- 4択（能力問題は五肢択一／2つ選ぶ形式）と、選択肢を1つずつ判定する○×形式
- 分野別・年度別・全分野ランダム・間違えた問題の復習
- 学習記録は端末のブラウザ内にのみ保存

過去問の問題文・正答は試験実施機関の公表資料によります。
