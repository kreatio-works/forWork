# 現場写真報告書

スマホで撮った現場写真を並べて、**PDF** と **Excel（.xlsx）** の写真報告書を作る単一HTMLアプリです。
サーバー不要・インストール不要。ブラウザだけで動き、データは端末のブラウザ内に保存されます。

## できること

- 報告書ごとに「並べ方」を選択
  - **対比（左右）**：1件＝左右2枚（指摘時／是正後 など）＋各コメント＋メモ
  - **アルバム**：1件＝写真1枚＋コメント＋メモ。写真を順に並べる
- 写真の呼び方を報告書ごとに変更（指摘時/是正後・施工前/施工後・着手前/完了・既存/改修後・自由入力）
- カメラ撮影／ライブラリ選択。写真は長辺1200px・JPEG70%に自動圧縮
- PDF保存：A4縦、1頁あたりの件数を選択（対比 3/2/1件、アルバム 6/4/2枚）
- Excel出力：写真をセル内に埋め込んだ報告書形式（A4縦・印刷設定・ページ区切りつき）
- 一覧：代表サムネ表示、タイトル検索、削除
- バックアップ：全データをJSONで書き出し／読み込み（機種変更時など）

## 使い方

1. `index.html` をブラウザで開く（GitHub Pages で公開すればスマホからも利用可）
2. 「新しい報告書を作成」→ タイトルと並べ方を選んで「作成」
3. 写真枠をタップして撮影または選択。コメント・メモを入力（自動保存）
4. 「PDF保存」または「Excel出力」

iPhone では Safari の「ホーム画面に追加」でアプリのように使えます。
ブラウザ内保存は永続を保証しないため、報告書はPDF/Excelにしたら控えを取り、
長期間使わないときはバックアップを書き出しておいてください。

## 技術メモ

- 単一HTML（HTML/CSS/JS）。外部ライブラリは CDN 読み込み
  - jsPDF 2.5.1 ／ html2canvas 1.4.1（PDF）
  - ExcelJS 4.4.0（Excel）
- 保存先は IndexedDB（DB名 `genba_photo_report`）。旧 localStorage データは初回起動時に自動移行
- 写真は data URI（JPEG）として報告書データに内包
