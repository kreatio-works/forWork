# 作業時間ログ

案件（工事）ごとの作業時間をスマホやPCから記録し、月ごとに案件別の時間と金額を集計する単一HTMLアプリです。
個人事業の外注作業（図面作成など）で、請求の根拠や会計ソフトへの入力前の集計に使うことを想定しています。

## できること

- **記録**：タイマー（開始→停止）または手入力（日付・案件・開始〜終了・休憩・内容）
- **一覧**：月・案件で絞り込み、その場で編集・削除
- **集計**：月ごとに案件別の実働時間・請求時間・金額、日別の内訳
- **請求時間の丸め**：15分／30分／1時間単位で切上げ、月合計に対してか1件ごとかを選択
- **Excel出力**：「集計」「明細」の2シート（A4印刷設定・オートフィルタつき）
- **案件管理**：発注元・時間単価・色（パレット式）・完了フラグ
- **控え**：JSONで保存・読み込み。記録はブラウザに自動保存

## 使い方

1. 設定タブで案件を追加（時間単価は任意。固定額の案件は空のままで可）
2. 記録タブで、作業開始時にタイマー「開始」→ 終了時に「停止して記録」→ 内容を書いて「記録する」
   - あとからまとめて入れるときは手入力欄へ
3. 集計タブで月を選び、必要ならExcel出力

## 技術メモ

- 単一HTML。外部依存はExcel出力用の ExcelJS（cdnjs）のみ
- 保存先 `localStorage`（キー `sagyo-log-v1`）。タイマーの進行中状態も保存されるので、ページを閉じても計測は続きます
- 実働 ＝ 終了 − 開始 − 休憩。終了が開始より前なら日またぎとして翌日扱い
- 金額 ＝ 丸め後の請求時間 × 時間単価（円未満四捨五入）
- Excelは書式のみで関数を使わないため、Excel 2016以降で開けます
