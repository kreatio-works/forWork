# 二次検定ドリル（2級建築施工管理技士）

2級建築施工管理技士 第二次検定の暗記対策用ドリルです。スマホでのスキマ学習を想定した単一HTMLアプリで、法規の穴埋め・工程表・用語・施工（躯体/仕上げ）の4分野を出題します。

## できること

- **法規**：条文の穴埋め問題。空欄ごとに選択肢から選んで一括判定
- **工程表**：バーチャート工程表に関する問題
- **用語**：用語の説明・留意点の練習
- **施工**：躯体・仕上げの4択問題（解説つき）
- **記録**：分野ごとの正答状況を保存し、苦手な問題（間違えて連続正解が続いていないもの）を優先出題
- **昨年出題フラグ**：昨年出た問題に印をつけ、「後回しで出す」「出さない」を選択
- **追加**：自分で問題を追加できる（法規・用語・施工など）
- 画面上部に試験日までのカウントダウンを表示

## 使い方

1. `index.html` をブラウザで開く（GitHub Pages のURLをスマホのホーム画面に追加すると使いやすい）
2. タブで分野を選び、出題範囲・出題方法（全問シャッフル／苦手優先 など）を選んでスタート
3. 間違えた問題は「記録」タブで確認。繰り返すうちに苦手優先で回転

## 技術メモ

- 単一HTML・外部依存なし。アイコンもdata URIで埋め込み
- 成績・追加問題・フラグは `localStorage`（キー `sekou2ji_v1`）に保存。端末ごとに独立
- 問題データはHTML内の配列（`LAW_Q` / `SCHED` / `TERMS` / `SEKOU_Q`）を直接編集しても増やせます
